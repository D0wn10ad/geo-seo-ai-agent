# GEO-SEO AI Agent Toolkit

Geo SEO Audit Toolkit for OpenCode. See [README.md](README.md) for full documentation.

## Quick Install

Install the pinned skills for both agents from this fork:

```bash
npx skills@1.9.0 add -a claude-code -a opencode -y https://github.com/D0wn10ad/geo-seo-ai-agent.git
```

Check and update an existing install with `npx skills@1.9.0 check` and `npx skills@1.9.0 update` (see `skills/geo-update/SKILL.md`).

## Commands

All 21 `/geo` commands are available as OpenCode command wrappers (`.opencode/commands/geo-*.md`).
