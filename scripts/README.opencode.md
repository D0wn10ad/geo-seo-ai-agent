# Scripts — GEO-SEO AI Agent Toolkit

Python utility scripts used by the GEO skills and agents.

## Key Scripts

- `fetch_page.py` — Fetch and parse web pages (page, robots, sitemap, llms.txt)
- `generate_pdf_report.py` — Generate professional PDF reports (ReportLab)
- `crm_dashboard.py` — CLI-based CRM for prospect management
- `update_toolkit.py` — Cross-platform installer/updater
- `webapp/app.py` — Flask + HTMX CRM web UI
